# ☕ Coffee Shop Sales Analysis

**Created by:** Rishu Raj

## 📊 Project Overview

This project is a Coffee Shop Sales Analysis created using Microsoft Excel.

The project analyzes coffee shop sales data and presents important business insights through an interactive Excel dashboard.

The dashboard helps understand sales performance, customer footfall, order trends, product performance, category-wise sales, store location performance, and hourly ordering patterns.

## 🎯 Project Objectives

- Analyze overall coffee shop sales performance
- Understand customer footfall and ordering behavior
- Identify top-performing products
- Analyze sales by product category
- Compare sales across different store locations
- Analyze orders by weekday
- Understand quantity ordered at different hours
- Present key insights using an Excel dashboard

## 🛠️ Tools & Techniques Used

- Microsoft Excel
- Data Cleaning
- Data Analysis
- Pivot Tables
- Pivot Charts
- Dashboard Creation
- Data Visualization

## 📈 Dashboard Features

The dashboard contains the following analysis:

### 🔹 Key Performance Indicators

- Total Sales
- Total Footfall
- Average Bill per Person
- Average Order per Person

### 🔹 Sales & Order Analysis

- Quantity Ordered Based on Hour
- Categories Distribution Based on Sales
- Size Distribution Based on Orders
- Total Sales Based on Store Location
- Top 5 Products Based on Sales
- Orders on Weekdays

## 💡 Business Insights

This dashboard provides a quick overview of coffee shop performance and helps identify:

- Overall sales performance
- Customer footfall trends
- Popular product categories
- Top-selling products
- Sales performance across store locations
- Customer ordering patterns during different hours
- Order distribution across weekdays
